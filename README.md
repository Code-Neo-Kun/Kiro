# Kiro Cursor

A modern, lightweight WordPress plugin that replaces the default browser cursor with beautiful animated cursor effects. Customize styles, animations, colors, and behavior directly from the WordPress admin panel—no coding required.

## Features

### Cursor Styles

Choose from 8 unique cursor styles:

* Dot + Ring
* Crosshair
* Arrow
* Spotlight
* Glitch
* Neon
* Ghost
* Emoji Star

### Animation Presets

Enhance the cursor experience with:

* Pulse
* Breathe
* Spin Ring
* Trail Particles
* Magnetic Snap
* None

### Customization Options

* Visual style picker
* Visual animation picker
* Custom cursor color
* Adjustable cursor size (4–60px)
* Disable cursor on mobile devices
* Lightweight and performance optimized
* Pure Vanilla JavaScript (no dependencies)

### Performance Features

* Smooth cursor movement powered by `requestAnimationFrame`
* Pool-capped particle system
* Optimized DOM rendering
* Two-layer architecture prevents animation conflicts
* Minimal memory footprint

## Installation

### Method 1: Upload Plugin

1. Download the plugin ZIP.
2. Navigate to **WordPress Admin → Plugins → Add New → Upload Plugin**.
3. Upload the ZIP file.
4. Click **Install Now**.
5. Activate the plugin.

### Method 2: Manual Installation

1. Upload the `kiro-cursor` folder to:

```text
/wp-content/plugins/
```

2. Activate the plugin from:

```text
WordPress Admin → Plugins
```

3. Configure the plugin under:

```text
Settings → Kiro Cursor
```

---

## Configuration

After activation, navigate to:

```text
Settings → Kiro Cursor
```

Available settings:

* Cursor Style
* Animation Preset
* Cursor Color
* Cursor Size
* Disable on Mobile

Changes are applied instantly on the frontend.
